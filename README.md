# EcoForge: AI Carbon Footprint Compiler (Chrome Extension)

EcoForge เป็น Chrome Extension ที่ใช้ปัญญาประดิษฐ์ (AI) ในการช่วยคำนวณคาร์บอนฟุตพริ้นท์และการวิเคราะห์จุดวิกฤตความร้อนเชิงคาร์บอน (Hotspot) สำหรับกระบวนการผลิตและการรีไซเคิลพลาสติก (Plastic Manufacturing & Recycling)

---

## 🌟 ฟีเจอร์หลัก (Core Features)

1. **AI OCR & Vision Parsing**: ใช้ Gemini API วิเคราะห์ภาพถ่ายมิเตอร์ไฟฟ้า, บิลค่าน้ำ หรือเอกสารรายงานล็อตการผลิตพลาสติกเพื่อดึงข้อมูลกิจกรรมโดยอัตโนมัติ
2. **Carbon & Circularity Calculator**: คำนวณปริมาณการปล่อยก๊าซคาร์บอน (tCO2e) โดยอ้างอิงปริมาณวัตถุดิบ, พลังงานไฟฟ้า, น้ำประปา และสัดส่วนพลาสติกรีไซเคิล
3. **Interactive Side Panel**: ทำงานร่วมกับการท่องเว็บผ่านแถบด้านข้าง (Side Panel) เพื่อบันทึกข้อมูลอย่างรวดเร็ว
4. **Sustainability Dashboard**: แสดงประวัติล็อตการผลิตและการวิเคราะห์เพื่อหาวิธีลดผลกระทบต่อสิ่งแวดล้อมอย่างมีนัยสำคัญ

---

## 📂 โครงสร้างไฟล์ในโปรเจกต์ (Project Files)

คุณต้องอัปโหลดไฟล์เหล่านี้ทั้งหมดขึ้น GitHub เพื่อให้ส่วนขยายทำงานได้อย่างสมบูรณ์:

* `manifest.json` — ไฟล์กำหนดค่าหลักของ Chrome Extension (Manifest v3)
* `sidepanel.html` & `sidepanel.js` — อินเทอร์เฟซและฟังก์ชันการทำงานของแถบด้านข้าง (Side Panel)
* `dashboard.html` & `dashboard.js` — แดชบอร์ดแสดงผลรวมและการวิเคราะห์ Hotspot คาร์บอน
* `styles.css` — สไตล์และโทนสีสำหรับการออกแบบ
* `background.js` — จัดการการทำงานเบื้องหลังและการทำงานร่วมกับ Side Panel
* `aiService.js` — บริการเชื่อมต่อและดึงข้อมูลด้วย Google Gemini API
* `carbonCalculator.js` — ตรรกะการคำนวณคาร์บอนฟุตพริ้นท์ของกระบวนการขึ้นรูปพลาสติก
* `storage.js` — ตัวจัดการจัดเก็บข้อมูลประวัติและค่าการตั้งค่าลง Chrome Storage

## 🚀 วิธีการทดสอบและติดตั้งใน Chrome (Developer Mode)

1. ดาวน์โหลดโค้ดทั้งหมดลงในเครื่องของคุณ
2. เปิดเบราว์เซอร์ Google Chrome แล้วไปที่ลิงก์: `chrome://extensions/`
3. เปิดใช้งาน **"Developer mode"** (โหมดนักพัฒนาซอฟต์แวร์) ที่มุมขวาบน
4. คลิกปุ่ม **"Load unpacked"** (โหลดส่วนขยายที่คลายซิปแล้ว) ที่มุมซ้ายบน
5. เลือกโฟลเดอร์ที่เก็บไฟล์ทั้งหมดของโปรเจกต์นี้
6. เริ่มต้นใช้งานได้ทันที! (อย่าลืมใส่ Gemini API Key ในหน้า Settings ของตัวส่วนขยาย)
